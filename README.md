# Loan Prediction ML Project

## Overview
This project predicts whether a loan application will be approved using machine learning.

## Dataset
Loan dataset containing applicant financial and demographic information.

## Models Used
- Logistic Regression
- Random Forest
- XGBoost

## Best Model
Logistic Regression (Accuracy: 78.8%)

## Features
- Data preprocessing
- Missing value handling
- Feature encoding
- Model comparison
- Streamlit web app

## How to Run

1. clone the repository
https://github.com/Tehmina521/AI_DS-Project
cd task1

2. Install dependencies
pip install -r requirements.txt

3. Run Streamlit

streamlit run app.py
