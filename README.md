# Loan Prediction ML Project

## Overview
This project predicts whether a loan application will be approved using machine learning.

## Dataset
Loan dataset containing applicant financial and demographic information.

## Models Used
- Logistic Regression
- Random Forest
- XGBoost

## Best Model
Logistic Regression (Accuracy: 78.8%)

## Features
- Data preprocessing
- Missing value handling
- Feature encoding
- Model comparison
- Streamlit web app

## How to Run

1. Install dependencies
pip install -r requirements.txt

2. Run Streamlit
streamlit run app.py


## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Jupyter Notebook
